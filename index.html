Політика конфіденційності «Світло»

Ця політика описує, як Android-застосунок «Світло» обробляє дані для показу графіків відключень електроенергії. З питань конфіденційності пишіть розробнику на birka2006@gmail.com.

Дані на вашому пристрої

Ви самі обираєте адресу або групу для перегляду графіка. Застосунок працює без реєстрації та не визначає геолокацію телефона. Назви карток, збережені адреси, групи, налаштування й прив'язки віджетів зберігаються на пристрої. Файл збережених карток зашифровано ключем, захищеним Android Keystore. Резервне копіювання засобами Android вимкнено.

Запити до джерел графіків

Для пошуку адреси, визначення групи та оновлення графіка застосунок звертається через HTTPS до джерел відповідного оператора. Залежно від оператора запит може містити пошуковий текст, назву або код населеного пункту чи вулиці, номер або код будинку. Частина джерел надає загальні графіки та повідомлення, які застосунок перевіряє на пристрої. Запити можуть повторюватися під час оновлення даних для збереженої адреси.

Одержувачі адресних запитів включають ДТЕК Дніпровські та Одеські електромережі, Житомиробленерго, Миколаївобленерго та Хмельницькобленерго. Застосунок також може читати публічні графіки та повідомлення на сайтах операторів, у публічних каналах Telegram та опублікованих таблицях Google. Сервери бачать IP-адресу з'єднання та службові дані HTTP. Для окремих запитів використовуються службові cookies джерела. Назву вашої картки, електронну пошту й номер телефона застосунок не додає до цих запитів.

Для групових підключень Львівобленерго та Прикарпаттяобленерго назва населеного пункту й назва картки залишаються на пристрої. До API Прикарпаттяобленерго надсилається обрана група, а API Львівобленерго повертає загальний графік груп. Ці запити не містять номера будинку, особового рахунку чи EIC-коду. Публічні повідомлення про аварійні відключення завантажуються без адреси користувача; зіставлення населених пунктів виконується на пристрої. Сервери джерел бачать IP-адресу HTTPS-з'єднання.

Розробник не отримує копії адресних запитів у власному сховищі. Оператори та інші джерела самостійно визначають порядок обробки й строки зберігання своїх серверних журналів.

Зберігання та видалення

Збережені картки залишаються на пристрої до видалення в налаштуваннях застосунку. Щоб видалити всі локальні дані «Світла», скористайтеся очищенням даних застосунку в налаштуваннях Android або видаліть застосунок. Це не видаляє записи, які могли залишитися в журналах зовнішніх джерел. З питань таких записів звертайтеся до відповідного джерела.
